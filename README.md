# Minutes for macOS

Records your calls, then gives you a transcript, a summary and proposed action items.

Download Minutes and read release notes on the [Releases page](https://github.com/ten-thousand-hammers/minutes/releases).

Minutes requires macOS 14.2 or later and supports Apple Silicon and Intel Macs.
The app checks for updates through GitHub releases. Use **Check for Updates…** in the Minutes menu to check manually.

This repository hosts downloads and release notes. Application source code is maintained separately.
